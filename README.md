# Introduction

Muxing is the owner of this repository. The goal of this repo is to patch up his math skills, minimize the probability of making mistakes, and deepen his understanding of these concepts.

The name **Oops2QED** represents exactly what it does: documenting the hard problems that initially stumped Muxing while studying Reinforcement Learning and related fields. It's a combination of LLM-generated insights, personal review, and knowledge management, ultimately distilled into concrete derivations and methodologies.

For the correct rendering and best reading experience, please open this repository directly with **Obsidian**.

The Agents currently contributing to this repo include:

* **Gemini-cli (Gemini 3.1 Pro):** The remote resources are always fully packed, making it painfully slow. Honestly, the official Gemini web interface responds much faster.
* **GPT-5.3-Codex:** Generous API quota, but speaks terrible natural language, constantly messes up my code, and absolutely *hates* writing math formulas in KaTeX.
* **Muxing (Human):** Very careful, but sometimes the brain just lags. Also, frequently too busy to actually review his own mistake book.

The files in the root directory are still under construction—there is zero guarantee of their correctness. However, anything in the `archive` folder is verified and safe to consume. If you find any errors in the archive, feel free to open an Issue and hammer me.
